# Soft-Stem Bulrush

*Schoenoplectus tabernaemontani*



![The plant Grey Club-rush, Schoenoplectus tabernaemontani.](img/soft-stem-bulrush-1.jpg)

![KRT3936](img/soft-stem-bulrush-2.jpg)

Schoenoplectus tabernaemontani is a species of flowering plant in the sedge family known by the common names grey club-rush, softstem bulrush, and great bulrush.

## Quick Facts

| | |
|---|---|
| **Scientific name** | *Schoenoplectus tabernaemontani* |
| **Family** | Cyperaceae |
| **Height** | 4-8 ft |
| **Bloom time** | Jun-Aug |
| **Sun** | Full sun |
| **Moisture** | Shallow water |
| **Soil** | Muck |
| **Wildlife value** | Nesting cover for marsh birds; seed for waterfowl; strong wave-energy buffer |
