# MicroSims

A MicroSim is a small interactive simulation built around a single idea. Each
one lives at `docs/sims/<name>/` and is embedded in the chapter it belongs to,
but every sim also works on its own — click any card below to open it full
size.

All 22 are implemented and live. Twenty-one are embedded in a chapter; the
Learning Graph Viewer stands alone as a map of the whole book.

## Using These in a Classroom

Every sim runs entirely in the browser with no login, no data collection and no
server. To embed one in your own course page, copy the iframe line from that
sim's page — for example:

```html
<iframe src="https://arunbatchu.github.io/minnesota-native-plants/sims/prairie-root-depth/main.html"
        height="600px" scrolling="no"></iframe>
```

They are licensed CC BY-NC-SA 4.0 along with the rest of the book, so you are
free to use and adapt them for non-commercial teaching with attribution.
